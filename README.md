## AI-assisted development in practice

On a commercial project I wrote the rules agents follow (CLAUDE.md and rule files) and built a Claude Code skill that takes a task from the tracker to a verified commit:

```text
Jira issue (via MCP) → branch → code + tests
  → lint · type check · tests · build
  → browser check with Playwright
  → commit → report back to Jira
```

Generated code always goes through manual review, and pushing and opening merge requests stay with a human. I also use agents to generate TypeScript models from OpenAPI specs, draft tests and pre-check changes before review.
